# Phase 03 — Context recognition (experimental)

Run `node knowledge/context-recognizer.test.mjs` from repository root with modern Node.js. No dependencies. The recognizer accepts Thai/English text and returns normalized text, intent with evidence, scored candidate topics with source locators, explicitly observed contextual mentions and quantities, observed/related modules, and abstention states. It returns no technical facts or captions and always sets generation_ready=false. Draft records remain unchanged. No integration with V2.1.27 runtime. Phase 04 will implement knowledge retrieval and validate records separately. Scores are lexical heuristics, not calibrated confidence. This test set was authored while implementing the recognizer; results are development checks, not independently measured accuracy. See context-report.v0.1.json for failures. Multiple questions should be passed as an array using analyzeMany; a single sentence can expose multiple topics. Some colloquial wording, generic terms, and multi-intent questions remain ambiguous.

Thai normalization preserves Sara Am after NFKC; additional 12 author-written challenge prompts and their results are recorded in the report. Neither set is independent.
