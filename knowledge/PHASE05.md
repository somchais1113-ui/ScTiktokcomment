# Phase 04 prerequisite + Phase 05 contextual caption (experimental)
Phase 04 was not present on develop at the start of this task. The retrieval module bridges Phase 03 to Phase 05 using direct matched candidates, their existing scores, strict approval/provenance/constraint gating and source traceability. Related modules remain review suggestions; broad cross-domain search and independent ranking evaluation are deferred.
The composer accepts one or more questions and settings (length, tone, variant, CTA, fixed tags); returns body, tags, combined, source locators, per-question analyses and review flag. Current 60 draft records produce question-led teasers only, no draft facts. For approved data, the primary record must be eligible; up to two directly matched approved records may be used in long mode, always with caveats. No auto-publishing. Do not interpret "grounded_draft" as automatic factual correctness or approval to publish. No corpus approvals or source document changes made. The current V2.1.27 UI/controller remains unchanged, including manual edit protection and local preset storage. Integration and Safari testing remain Phase 07. 
Run node knowledge/contextual-caption.test.mjs from the repository root with modern Node. Report contains actual JavaScript development checks and synthetic approval-path tests, not independent accuracy. No API needed.
